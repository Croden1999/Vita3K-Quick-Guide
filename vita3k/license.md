# 授权安装
如果应用程序/游戏缺少license授权文件可能导致无法运行应用（指pkg/nonpdrm zip安装后），安装授权即可正常解密运行。
1. 打开Vita3K，PC在顶部菜单栏点击`文件`->`安装授权（rif/work.bin）`；Android在主页中点击右下角`+`->`授权`；
2. `选择bin/rif文件`或`手动输入rzif密钥`，授权文件或密钥需要与你要启动的游戏ID对应一致；
3. 完成授权安装后，运行游戏即可；
4. 如果仍然出现运行错误，建议检查并按照步骤重新安装授权。
